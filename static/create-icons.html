PWA Icon Generator

To create PWA icons, you can:

  1. Use an online tool like RealFaviconGenerator
  2. Use PWA Builder Image Generator
  3. Create a 512x512px icon with the VICTUS logo and use it to generate all sizes

Required icon sizes:

  • 72x72
  • 96x96
  • 128x128
  • 144x144
  • 152x152
  • 192x192
  • 384x384
  • 512x512

Place all generated icons in the /static/icons/ directory.

For now, you can use a simple colored square as a placeholder until you create proper icons.
